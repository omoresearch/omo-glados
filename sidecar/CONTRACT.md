# Omo GLaDOS: sidecar contract

The HTTP API between the MuJoCo sidecar (`sidecar/`) and the Fabric client mod (`mod/`). Anything that speaks it
can drive her: another renderer, a voice backend, a chat bridge.

## Ground rules

- Loopback only: `127.0.0.1:8794` (`GLADOS_PORT` overrides). Never `0.0.0.0`. JSON, no auth.
- Sim frame: MuJoCo world, z-up, metres. Origin = the ceiling mount point (underside of the ceiling); she hangs
  in -z. Quaternions `[w,x,y,z]`. At rest the eye looks along sim +x.
- Bodies, root first: `mount` (fixed) -> `arm1` -> `arm2` -> `torso` -> `neck` -> `head`.
- The model is original procedural geometry generated by `glados_model.py` (no Valve assets).

## Endpoints

| Method + path | Body / reply |
|---|---|
| `GET /health` | `{"ok":true,"mode":"idle","t":12.3,"hz":60, ...}` plus diagnostics: `seq talk eye sleeping player player_fresh player_dist yaw_deg overruns step_ms resets nan_resets cmds triangles scale_hint model rev` |
| `GET /model.json` | the active model (v3 asset format below) plus `"rev":N` and `"atlas":"/atlas.png?rev=N"` |
| `GET /atlas.png` | the active model's texture atlas (PNG RGBA, v = 0 at the top row) |
| `GET /models` | `{"active":"procedural","rev":N,"models":[{"name","title","credit","triangles"}]}` |
| `GET /pose` | `{"seq":1,"t":1.2,"mode":"track","talk":0.0,"eye":[r,g,b,glow],"rev":N,"bodies":{"mount":[px,py,pz,qw,qx,qy,qz],...}}` |
| `POST /cmd` | `{"cmd":..., "from":"mc"\|"voice"\|"twitch:<user>"}` -> `{"ok":true,"mode":...}` / `{"ok":false,"error":...}` |
| `POST /player` | `{"x":..,"y":..,"z":..}` the player's EYE position in sim metres (~5 Hz). All three required (400 otherwise). |
| `POST /config` | `{"scale_hint":x}` stored and reported only |

`talk` is the current speech level 0..1 (she has no mouth: it drives a head bob and the eye pulse). `eye` is the eye
colour 0..1 plus glow 0..1: yellow normally, red-orange while `angry`, dim while asleep. `rev` changes on every model
switch and across restarts, so a client refetches `/model.json` when `/pose.rev` differs from its model's `rev`.

## Commands (`POST /cmd`)

| cmd | What she does |
|---|---|
| `idle` | breathing sway, slow glances round the room (35 % at the player if known). Default. An explicit `idle` suppresses auto-track for 20 s. |
| `track` | the eye follows `/player`. Automatic when your eye is < 12 m from her head and `/player` is < 5 s old; an explicit `track` holds up to 30 m. |
| `look` + `"dir":"left"\|"right"\|"up"\|"down"\|"player"` | one 2.2 s glance, then back |
| `angry` | 4 s: eye red-orange, neck/head gains x1.6, jerks every 70-140 ms, two lunges toward the player |
| `scan` | 5 s sweep +70° -> -70° -> +70° across the room |
| `nod` / `shake` | 1.8 s yes / no |
| `bow` | 3 s: neck and head pitch down toward the player |
| `sleep` / `wake` | droop over 2.5 s with a dim eye, held until `wake` (or any other non-talk cmd) |
| `dance` | 8 s at 112 BPM: head bob per beat, sway, the whole chain circles |
| `spooky` (`spookydance`, `creepy`) | ~18.6 s: power-down sway, glitch dance, a swoop to ~1.5 m from the player's eye, a held stare, pull back |
| `talk` | `{"on":true}` (60 s cap) / `{"on":false}` / `{"duration":s}` / `{"level":0..1}` (~10 Hz from a voice backend) |
| `model` + `"name"` | switch the active model live (~0.1 s, mode kept); 400 on an unknown name |
| `reset` | design pose, all state cleared |

Commands tagged `"from":"twitch:<user>"` may only use `idle track look angry scan nod shake bow sleep wake dance
spooky` (anything else is 403); `spooky` from Twitch has a 60 s cooldown (429 + `retry_after`).

## Minecraft mapping (done in the mod)

Anchor A = `(ax, ay, az)`, the MC coordinates of the sim origin (the ceiling underside); scale `s` (default 1.0).
MC position of sim `p=(x,y,z)`: `(ax + s*x, ay + s*z, az - s*y)`. Rotations `R_mc = C R C^T` with `C(x,y,z) = (x,z,-y)`
(quaternion `[w,x,z,-y]`). Player eye (MC) -> sim: `((px-ax)/s, -(pz-az)/s, (py-ay)/s)`. The optional `yaw`
(degrees) turns the whole model about the anchor's vertical axis, applied to both the render and the player->sim
conversion.

## Model format (v3 asset, `assets/<name>/asset.json` + `atlas.png`)

```
{"version":3, "name":"procedural", "title":"...", "credit":"<author, licence, url>",
 "bodies":[{"name":"mount","parent":null,"joint_pos":[x,y,z],"rest":[px,py,pz,qw,qx,qy,qz]}, ... arm1, arm2, torso, neck, head],
 "meshes":[{"body":"torso","name":"...","verts":[...],"normals":[...],"uv":[u,v,...],"tris":[...],
            "rgba":[r,g,b,a], "tag":null|"eye"|"emissive"|"glass",
            "skin":null|{"bodies":["arm2","torso"],"j":[a,b,...],"w":[w,...]} }],
 "eye":{"body":"head","pos":[x,y,z],"axis":[x,y,z]}, "voice":{"body":"head","pos":[x,y,z]},
 "atlas":"atlas.png", "triangles":N}
```

- Same six bodies the sim uses. `rest` = body world pose at the rest pose; `joint_pos` = joint anchor in the parent
  frame (the sim builds its MjSpec chain from these). Rigid mesh verts are body-local.
- Skinned meshes (cables spanning two bodies): verts in the sim-world rest frame, two body indices `j` per vertex
  and the weight `w` of the first; the mod does `v = w*T_a*R_a^-1*v + (1-w)*T_b*R_b^-1*v`.
- Tags: `eye` = fullbright, tinted by `pose.eye`; `emissive` = fullbright; `glass` = translucent pass.
- Frame: ceiling -> lowest point 7.5-8 m, top face at or below z = 0, eye axis along +x. Budget <= 40,000 triangles,
  atlas <= 4096 px. `glados_assets.py check` is the gate.
- Only `procedural` ships. If you add your own model, you are responsible for its licence; `credit` is shown in
  game by `!glados help` and `!glados models`.

## Voice (optional; backend not included)

The mod's Simple Voice Chat plugin talks to a voice backend over a loopback WebSocket, default
`ws://127.0.0.1:8793/svc` (config `glados-voice.properties`, `url`):

- binary frames = PCM16 LE mono 48 kHz, both directions (mic to the backend, her reply back);
- JSON text frames `hello` / `start` / `ptt` / `hangup` from the mod, `status` / `transcript` / `clear` to the mod.

A backend may also send `talk` levels and body commands (`"from":"voice"`) to the sidecar while she speaks. The
reply plays on a positional channel at her head. Mic focus: she owns the mic when you are within `hear_range` of
her head and either look within `look_angle` of it or stand closer to her than to an Omo Microduck; while she owns
it she sets the JVM property `omo.voice.focus` to `glados:<millis>` every tick.

## Physics budget

60 Hz control, 480 Hz physics (`implicitfast`, 8 substeps), single-threaded (`OMP_NUM_THREADS=1`), `Nice=10`,
RSS < 250 MB. There is no trained policy: the "brain" is a scripted behaviour layer (PD targets, look-at IK)
on top of real rigid-body dynamics.
